# 羽田 到着便の遅れ（Flightcheck）

時間帯を入れてボタンを押すと、羽田に着く便のうち遅れている便を一覧で表示します。
GitHub Pages で公開する、完全無料のツールです。

## できること

- 「18:00〜20:00」のように時間帯を指定して、遅れている便を表示
- 遅れの基準（5 / 15 / 30 / 60分以上）、国内線・国際線の絞り込み
- 欠航・行き先変更の便も表示（オフにもできる）
- 便ごとの推定人数と、遅れ便の推定人数の合計
- 遅れが大きい順 / 予定時刻順の並べ替え、行をタップで詳細表示

## 費用

すべて無料です。

| 使うもの | 費用 |
|---|---|
| ODPT（運航データ） | 無料（開発者登録が必要） |
| GitHub Pages（公開） | 無料 |
| Cloudflare Workers（パスワードで人に使ってもらうときの中継） | 無料プランで足ります |

## Claude Code に頼むとき

このフォルダで Claude Code を開き、次のように頼めば進めてくれます。手順は `CLAUDE.md` に書いてあります。

- 「CLAUDE.md を読んで、GitHub Pages に公開して」
- 「ODPTのトークンが届いたので、本物のデータで動作確認して」（トークンはチャットで渡し、ファイルには書かせない）
- 「直接つながらなかったので、中継を立てて」

## 使い方

1. 公開されたURL（`https://kozo114.github.io/flightcheck/`）をスマホで開く
2. 初回に「設定」が開くので、パスワードを入れて保存する
   ODPTのアクセストークンを持っている人は、「詳細設定」のトークン欄に入れれば中継を通さず直接つながる
   どちらもその端末のブラウザにだけ保存され、GitHubには送られません
3. 時間帯を選んで「遅れている便を探す」を押す

ホーム画面に追加しておくと、アプリのように使えます。
見た目だけ確かめたいときは、URLの最後に `?demo` を付けるとサンプルデータで表示されます。

## 推定人数について

航空会社は便ごとの搭乗者数を公開していないため、**座席数 × 平均的な搭乗率**で目安を出しています。

- 機材がわかる便 … 機材の座席数から計算（「機材から推定」）
- 機材がわからない便 … 路線から機材の大きさを推定（「路線から推定」）

搭乗率は「設定 → 詳細設定」で変えられます（初期値：国内線 72%、国際線 80%）。

## 人に使ってもらうとき（パスワード）

ODPT の規約で、アクセストークンを他の人に教えることはできません（利用規約 第5条）。
そのため、トークンは Cloudflare の中継（`relay-worker`）の中に隠し、パスワードを知っている人だけがその中継を通してデータを見られるようにしています。

- トークンとパスワードは Cloudflare の secret（`ODPT_KEY` / `ACCESS_PASSWORD`）に置き、このリポジトリには書きません
- 中継は ODPT へ1分に1回までしか問い合わせないので、使う人が増えても ODPT に負担をかけません
- パスワードを変えたいときは `npx wrangler secret put ACCESS_PASSWORD` で登録し直します

## つながらないとき

「ブラウザからODPTに直接つながりませんでした」と出る場合は、ODPTがブラウザからの直接アクセスを許可していない可能性があります。
その場合は `relay-worker` フォルダの中継を Cloudflare（無料）に公開し、そのURLを「設定 → 詳細設定 → 中継URL」に入れてください。
Claude Code に「中継を立てて」と頼めば、`CLAUDE.md` の手順で進めてくれます。

| 表示 | 対処 |
|---|---|
| パスワードが未設定です | 右上の歯車から設定を開き、パスワードを入れる |
| パスワードが違います | 教えてもらったパスワードを入れ直す |
| アクセストークンが無効か、まだ有効になっていません | 開発者サイトで登録完了を確認し、入れ直す |
| 短時間に検索しすぎました | 1分ほど待ってから探す |
